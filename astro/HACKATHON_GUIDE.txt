  WHAT IS IT?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  Real-time satellite orbit monitoring + anomaly detection system.
  Compares a physics-based predicted orbit against actual TLE-observed orbit.
  Any mismatch = anomaly. Visualised on a live 3D Earth.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  TLE from CelesTrak
    -> SGP4 propagation         (what the TLE says the satellite IS doing)
    -> RK4 physics prediction   (what physics says it SHOULD be doing)
    -> Compare: delta-r, delta-v in RSW frame
    -> Classify: NORMAL / WATCH / WARNING / CRITICAL
    -> Stream to frontend via WebSocket @ 2 Hz
    -> Render on Three.js 3D Earth with live charts + alerts

  PHYSICS USED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  SGP4      : Analytical orbit propagation from TLE (NORAD standard)
  RK4       : 4th-order Runge-Kutta numerical integration
  J2        : Earth oblateness perturbation (orbital plane precession)
  Drag      : Exponential atmospheric density model (a_drag = -½ CD A/m ρ v_rel²)
  RSW Frame : Radial / In-track / Cross-track error decomposition
  COE       : Classical Orbital Elements (a, e, i, Ω, ω, ν, T)
  Geodetic  : Bowring's iterative ECEF -> WGS-84 lat/lon/alt conversion
  GMST      : IAU-76 Greenwich Mean Sidereal Time for ECI <-> ECEF rotation

  COMMON JUDGE QUESTIONS & ANSWERS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Q: Where does the satellite data come from?
A: TLE (Two-Line Element) sets from CelesTrak — the public NORAD/Space Force
   catalogue. Updated via async HTTP fetch; cached locally as JSON fallback.

Q: What is a TLE?
A: Two-Line Element set. A compact text format used by NORAD since the 1970s
   encoding a satellite's orbital state (6 Keplerian elements + drag + epoch)
   good for ~days of propagation.

Q: Why compare SGP4 vs RK4?
A: SGP4 uses the TLE's mean elements (may be stale, model-limited).
   RK4 uses current physical laws (J2 + drag) from the same starting state.
   Divergence over time reveals real orbital changes: manoeuvres, drag spikes,
   or TLE inaccuracies.

Q: What is J2 perturbation?
A: Earth isn't a perfect sphere — it bulges at the equator. This extra mass
   makes satellite orbital planes precess over time. J2 = 0.00108263 is the
   second zonal harmonic coefficient of Earth's gravity field.

Q: What is RSW?
A: Radial / In-track (along-track) / Cross-track — a satellite-centred
   rotating frame. Decomposing errors into RSW tells you:
   Radial = altitude error, Along-track = phase/manoeuvre signature,
   Cross-track = inclination/plane change.

Q: What does the "What Happened?" modal do?
A: It compares pre- and post-event Keplerian elements (delta-a, delta-e,
   delta-i, delta-v), runs a likelihood engine, and ranks probable root causes
   (manoeuvre, drag spike, ephemeris update) with a confidence percentage.

Q: Is this real-time?
A: Yes. WebSocket at 2 Hz for active satellite, 1 Hz for fleet overview.
   Position, velocity, deviation, and all Keplerian elements update live.

Q: What's novel / unique about this?
A: Most satellite trackers only visualise position. AstroTrace adds a
   numerical physics prediction layer, computes deviations in the RSW frame,
   classifies anomalies with configurable thresholds, lets you inject
   real-world orbital events (manoeuvres, drag spikes, deorbit burns) and
   instantly see the divergence between nominal and deviated orbits on the
   3D globe — all in real-time on a web browser with no plugins.

Q: What are the limitations?
A: TLE freshness depends on CelesTrak publish rate (hours to days).
   Atmosphere model is exponential (not NRLMSISE-00).
   No third-body (Moon/Sun) perturbations or solar radiation pressure yet.
